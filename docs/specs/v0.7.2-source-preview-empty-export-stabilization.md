# V0.7.2 Source Preview and Empty Export Stabilization Spec

## Status

Active design note for V0.7.2.

## Intent

Add a small stabilization step before expanding downstream workflows.

The goal is to make local trial runs safer and more inspectable:

- Preview source configuration and planned queries without network access.
- Avoid overwriting the current candidate export when a pipeline run collects no records.

This is not a new source, ranking, reading workflow, or integration milestone.

## Scope

In scope:

- Add a `src.main` source-preview path that reads runtime config only.
- Show enabled sources, disabled sources, source type, planned `SourceQuery` labels, per-source limits, and estimated max records.
- Keep source preview offline and free of source client network calls.
- Add empty-export protection in `run_pipeline()`.
- Return a controlled pipeline result when empty export is skipped.
- Add `--allow-empty-export` for explicit empty JSONL export writes.
- Add focused tests for source preview and empty-export protection.
- Update maintained docs that describe commands, architecture, and current active spec/plan.

Out of scope:

- New source clients.
- PDF downloading.
- LLM ranking or LLM summaries.
- Zotero, Obsidian, Anki, Telegram, or email integration.
- Vector databases.
- OpenReview, CORE, or IEEE client implementation.
- Google Scholar or publisher HTML scraping.
- SQLite schema changes.
- JSONL export format changes.

## CLI Contract

Preview command:

```bash
uv run python -m src.main --source-preview
```

Equivalent dry-run alias:

```bash
uv run python -m src.main --dry-run
```

The preview must not access the network and must not write crawl data, raw responses, SQLite rows, or candidate exports.

Default pipeline behavior:

```bash
uv run python -m src.main
```

If no records are collected, the command logs a clear warning and skips writing the current candidate export.

Explicit empty export:

```bash
uv run python -m src.main --allow-empty-export
```

This flag preserves the previous behavior for callers that intentionally want an empty JSONL file.
