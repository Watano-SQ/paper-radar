# AGENTS.md

## 作用范围

本文件适用于 `data/` 目录。该目录保存本地 SQLite 数据库、原始 API 响应、候选集导出和报告产物，是运行时数据区，不是当前项目事实源。

## 红线

- 不要删除、重建或清空 `data/papers.sqlite`，除非任务明确需要且风险已说明。
- 不要把原始响应、JSONL 导出或报告产物当作保留文档。
- 不要提交可能包含私人查询、抓取记录或敏感上下文的运行产物，除非人类明确要求。
- 不要凭旧导出文件推断当前代码能力。

## 工作规则

- 修改或清理本目录前，先检查 `.gitignore` 和相关任务说明。
- 运行会写入本目录的命令前，先检查 `config/sources.yaml` 的启用来源和限额。
- 需要样本数据时，优先使用最小样本或测试夹具，不要依赖私人本地数据库。

## 同步要求

- 当本目录改变项目架构、模块边界或公开行为时，评估是否更新 `docs/architecture.md`。
- 当本目录改变长期决策、设计取舍、风险或债务时，评估是否更新 `docs/changes.md`。
- 当本目录改变验证方式、运行命令、预期产物或环境要求时，评估是否更新 `docs/testing.md`。
- 当本目录规则变化时，评估根 `AGENTS.md` 是否需要同步说明。
- 其他保留文档只在事实源确实变化时更新。
